# 애드센스 품질 개선 진행표

대상: analogblow.com / 파주운정라이프
목표: 동일한 내부 평가 기준으로 80점대 이상.
이 점수는 Google 점수나 승인 확률이 아니다. 기존 심화 진단의 62/100을 기준선으로 두고 전체 재검증 후 다시 평가한다.

## 단계와 완료 조건

| 단계 | 현재 상태 | 완료 조건 |
| --- | --- | --- |
| 1. 데이터와 화면 문구 일치 | 부분 완료 | 실제 장소와 검색 안내 구분, 자료 기준일·출처·빈 상태 표시. 저장된 원자료와 실시간 결과를 구분한다. |
| 2. 대표 글 8~12편 보강 | 진행 중, 이번 묶음 3편 수정 | 구체적인 지역 대상, 이용 판단 기준, 직접 연결된 근거, 확인 범위, 모바일 검증을 갖춘다. |
| 3. 저가치 URL 검토 | 대기 | 전체 URL을 유지·개선·통합·정리로 판정하고 검색·사이트맵·내부 링크의 범위를 맞춘다. |
| 4. 편집 신뢰성 | 수정 글부터 적용 | 편집일과 원자료 날짜를 구별한다. 본문·schema·사이트맵을 맞추며 사실 확인 없이 날짜만 갱신하지 않는다. |
| 5. 모바일·배포·재평가 | 이번 묶음 검증 진행 | 핵심 페이지 360·390·430px, 링크, 원문 표시, GitHub·Cloudflare 공개 반영 확인 후 재평가한다. |

## 이번 묶음의 변경

### 똑버스 가이드

- 경기교통공사 호출방법 원문을 직접 읽어 인원 선택, 결제 방식, 승하차 절차를 요약했다.
- 근거가 없던 20~30분 대기 여유 제안을 제거하고 앱의 목적지 도착 예상시각을 비교하도록 수정했다.
- 운정역·야당역·운정중앙역의 목적지 구분, 환승 이동 여유, 교하 이동 시 권역 확인을 추가했다.
- 파프리카를 학원 이동 대안으로 일반화하지 않고 학교·노선·시간 확인이 필요한 통학 교통으로 설명했다.
- 운행지역 페이지는 접근했으나 파주 상세 목록 조회가 500으로 실패했다. 확정 요금·막차·권역 정보를 추가하지 않았다.
- 공식 본문 확인일과 편집일: 2026-09-20. 원문 자체의 갱신일은 미확인.

### 호수공원·카페 가이드

- 이전 버전은 저장된 JSON을 읽은 것을 당일 교차 확인처럼 표현했다. 이번에는 공개 원문을 실제 조회하고 확인 범위를 정정했다.
- 제이콥·브런치빈은 다이닝코드의 주소·장소정보, 아티장베이커스는 스타필드 공식 층별 안내를 연결했다.
- 카페당 원문은 이번 점검에서 조회하지 못해 이 글의 비교 대상에서 제외했다. 폐업이나 부적합으로 판단한 것은 아니다.
- 주소와 출처를 카드에 표시하고 제3자 정보·공식 정보·편집 제안을 구분했다.
- 와동동 대체 장소를 호수공원에서 이어지는 도보 코스나 완전한 실내 동선으로 단정하지 않는다.
- 현장 방문·전화 검수는 하지 않았다. 영업·주차 조건의 당일 확인이 남아 있다.
- 잘못된 AdSense 스크립트 경로를 정상 경로로 복구했다.

### 데이터·메타데이터

- 공개 API 재확인: 주차장 9건, 작은도서관 46건. 저장된 공식 자료를 제공하는 방식이며 실시간 주차 현황이 아니다.
- 병원 API: 요청한 3건 반환. 기관 기본정보이며 당일 진료 가능 여부를 뜻하지 않는다.
- 정책 API: fallback 3건. 뉴스 3건이 아니라 공식 확인처 안내이므로 실제 뉴스 연결 완료로 계산하지 않는다.
- 캘린더 schema를 본문과 같은 일정 확인 가이드로 정정했다. 확정 행사 목록은 아직 없다.
- 수정한 두 글의 본문·Article.dateModified·사이트맵 lastmod를 2026-09-20로 맞췄다.

### GTX-A 운정중앙역 환승·주차 가이드

- 2026-09-21 파주파킹을 재확인해 운정중앙역1·2를 분리하고 주소·면수·요금·월정기 조건을 표로 정리했다.
- 현재 운영값은 파주파킹, 개통 당시 임시 주차장 규모와 조성 경위는 파주시 공지로 구분했다.
- 역1은 585면·월정기 불가, 역2는 782면·월정기 가능으로 표시된 현재 포털 값을 반영했다. 만차 여부와 환승 할인은 실시간·현장 확인 대상으로 남겼다.
- 근거 없이 고정한 이동 여유 시간 표현을 제거하고, 열차 구간 시간과 전체 통근 시간을 분리했다.
- 본문·Article.dateModified·article:modified_time·사이트맵 lastmod를 2026-09-21로 맞추고 GitHub main에 배포했다.

## 검증 기록

- 로컬: 두 글의 JSON-LD, canonical, H1, 날짜, AdSense 스크립트, 내부 링크 통과.
- 로컬: 캘린더 JSON-LD 파싱과 제목 일치 통과.
- 모바일·공개 배포 검증: GTX 글 200 응답, 최신 표·출처·사이트맵 반영 확인. 핵심 대표 글 전체 모바일 검수는 남아 있다.
