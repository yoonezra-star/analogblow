# 파주운정라이프 애드센스 승인 심화 진단

점검일: 2026-09-20  
대상: `https://analogblow.com`  
범위: 공개 사이트, 정적 소스, 사이트맵, 주요 API 응답, 모바일 390px 화면, 현재 AdSense 사이트 상태

## 1. 결론

현재 내부 진단 점수는 **62/100(대략 60~65 범위)**로 평가한다. 이 수치는 Google의 공식 점수가 아니라, 승인에 영향을 줄 가능성이 높은 품질 신호를 같은 기준으로 추적하기 위한 내부 지표다. 90점 이상을 목표로 삼을 수는 있지만, 특정 점수가 승인이나 승인 확률을 보장하지는 않는다.

현재 AdSense에서 `analogblow.com`은 **준비 중**이며, 소유권 확인과 리뷰 요청은 완료되어 있다. 따라서 지금은 사이트를 삭제하거나 재요청하는 단계가 아니라, 검토 중인 사이트의 실질적인 정보 가치를 높이고 변경 이력을 안정적으로 유지해야 한다.

Google의 안내는 최소 글자 수나 페이지 수를 제시하지 않는다. 대신 독창적이고 유용한 내용, 방문자가 다시 찾을 이유, 명확한 탐색 구조, 복제·재작성에 그치지 않는 부가가치를 강조한다. `noindex`는 검색 색인을 제어하는 기술 신호일 뿐, 낮은 가치의 내용을 자동으로 품질 심사에서 해결해 주는 장치가 아니다.

## 3. 확인된 강점

- 사이트맵 기준 84개 URL이 모두 HTTP 200으로 응답했고, 사이트맵 URL의 canonical이 자기 URL과 일치했다.
- 54개 기사와 30개 허브·정보 페이지가 구분되어 있어 구조를 확장할 기반은 있다.
- `ads.txt`는 `google.com, pub-1441018945572157, DIRECT, f08c47fec0942fa0`로 공개되고 계정 게시자 ID와 일치한다. AdSense 화면에 보이는 `Ads.txt 찾을 수 없음`은 최신 크롤 결과가 아직 반영되지 않은 상태일 수 있으므로, 현재 파일을 불필요하게 삭제하거나 바꾸지 않는다.
- 개인정보처리방침, 이용약관, 문의, 편집정책 등 기본 신뢰 페이지는 존재한다.
- GTX 운정중앙역 환승·주차 글처럼 명칭, 주차장, 요금, 이동 구간, 출처를 함께 제시한 글은 현재 사이트에서 상대적으로 강한 기준점이다.
- 카페 데이터에는 실제 장소명·주소·영업시간·주차·출처 필드가 있어, 원자료를 확인하고 편집자 검수를 붙이면 지역형 콘텐츠의 기반으로 활용할 수 있다.

## 4. 승인 관점의 주요 문제

### P0. 제목과 본문의 지역 정보 밀도가 맞지 않는 글

`unjeong-lake-cafe-walk-course`는 호수공원 산책과 카페 선택 방법을 설명하지만, 특정 카페·실제 경로·입구·거리·주차 조건이 거의 없어 제목의 기대를 충분히 채우지 못한다. `culture-free-indoor-weekend`도 실제 시설명·운영시간·예약·비교표보다 일반적인 실내 활동 선택법에 가깝다.

개선 기준은 “운정에서 어디를, 어떤 조건으로, 어떤 순서로 이용할지”를 한 글 안에서 결정할 수 있게 하는 것이다. 실제 확인하지 않은 방문 경험이나 숫자를 만들면 안 되며, 공식 자료로 확인한 정보와 편집자의 비교·정리를 분리해서 표시해야 한다.

### P0. 화면에 표시되는 기능과 실제 데이터의 차이

- 정책뉴스 화면은 현재 최신 뉴스 목록보다 공공 포털 링크와 일반적인 확인 안내가 중심이다. “최신 뉴스”를 표방한다면 날짜·제목·기관·원문 링크가 있는 실제 항목이 필요하고, 그렇지 않으면 페이지 제목과 설명을 “정책 확인 가이드”처럼 정직하게 조정해야 한다.
- 캘린더는 “이번 주”를 약속하지만 실제 일정 목록이 없어 방문자가 날짜를 확인할 수 없다. 날짜가 있는 행사만 보여주거나, 행사 수집 전까지는 “행사 찾는 방법” 페이지로 명확히 운영해야 한다.
- 주차 데이터 페이지는 비교 가능한 주차장 행보다 가이드 링크 중심이다. 데이터 페이지로 남길 경우 위치·운영시간·요금·확인일·출처가 있는 행을 제공해야 한다.
- 지도 검색의 병원 결과는 실제 의료기관 명부라기보다 일반 키워드와 좌표를 카드처럼 표시하는 구조다. 실제 기관명·주소·좌표를 검증하지 않았다면 지도 핀과 “검색 결과” 표현을 제거하고 “검색어 바로가기”로 표시해야 한다. 잘못된 위치 정보는 품질보다 먼저 신뢰 문제다.

### P1. 기사 간 편집 상태와 출처 연결 불일치

54개 기사 중 33개에서 본문 상단의 최종 점검일, 하단 안내일, 구조화 데이터의 `dateModified`가 다르다. 방문자는 최신 글인지 판단하기 어렵고, 오래된 정보가 새 글처럼 보일 수 있다.

기사마다 다음을 하나의 규칙으로 통일한다.

- `최종 확인`: 실제로 내용과 원문 링크를 점검한 날짜
- `원자료 기준일`: 공공기관 공지나 요금표의 기준일
- `다음 확인 예정`: 교통·요금·운영시간처럼 변동성이 높은 정보에만 표시
- 원문 링크: 기관의 해당 공지·페이지를 직접 연결

9개 기사에는 본문에 직접 연결된 외부 출처가 없어, 해당 글의 핵심 사실이 자체 편집 판단인지 외부 자료인지 구분하기 어렵다. 모든 글에 출처를 억지로 붙일 필요는 없지만, 날짜·요금·운영시간·자격 조건을 말하면 그 주장 옆에 직접 근거를 둔다.

### P1. 제외 처리와 검색·내부 링크 범위가 일관되지 않음

코드 규칙상 게시물 347개 중 282개가 `noindex`이고, 사이트맵에 실질적으로 노출되는 기사는 54개로 계산된다. 그러나 검색 스크립트에는 수리 카테고리와 제외된 지역 서비스·업체 상세 링크가 남아 있다. `noindex`를 많이 지정하는 것보다, 각 URL을 “유지·개선·통합·정리”로 편집 판정하고 사이트맵·검색·내부 링크·리디렉션을 같은 목록으로 관리하는 것이 중요하다.

제외된 카페·업체 상세 페이지를 URL 이름만 보고 일괄 폐기하지 않는다. 실제로 유용한 검증 정보가 있으면 보강 후 유지하고, 비슷한 글이 여러 개면 하나의 비교 허브로 통합한다. 내용이 없는 페이지를 유지하기 위해 301로 다른 주제에 보내는 것도 피한다.

### P2. 모바일 첫 화면과 탐색 밀도

390px 화면에서 문서 전체의 가로 overflow는 확인되지 않았다. 다만 홈에서는 큰 영웅 영역과 이미지 뒤로 핵심 카테고리가 첫 화면 아래로 밀리고, 지도는 필터가 길어 실제 결과에 도달하는 데 시간이 걸린다. 카테고리·검색·주요 정보 허브를 먼저 보여주고 세부 필터는 접어두는 방향이 적합하다.

## 5. 단계별 실행 계획

### 1단계: 데이터 진실성 정리

대상: 지도, 정책뉴스, 캘린더, 주차 데이터

완료 기준:

- 화면에 보이는 모든 장소·기관·뉴스·행사에 이름, 기준일, 출처 링크가 있다.
- 검증하지 않은 좌표·요금·운영시간·최신성 표현을 제거하거나 “확인 방법”으로 명시한다.
- 데이터가 없을 때 빈 상태와 마지막 확인일을 보여준다.
- 지도는 실제 검증된 시설 결과와 키워드 검색 바로가지를 시각적으로 구분한다.

### 2단계: 대표 콘텐츠 8~12개 재편집

첫 작업 묶음은 다음 순서가 적절하다.

1. GTX 운정중앙역 환승·주차 종합 가이드
2. 운정 주말·야간 약국과 소아 진료 확인 가이드
3. 파프리카 학교·통학 이동 정보
4. 운정 도서관 3곳과 실제 프로그램 확인법
5. 운정 호수공원 산책·카페 실제 선택 코스
6. 검증된 카페 4~6곳 비교표
7. 가족 지원 제도 3개 비교와 공식 자격 확인 경로
8. 운정 이사 직후 행정·생활 체크리스트

각 글은 문제 정의, 운정의 구체적인 대상, 비교표 또는 단계, 예외 조건, 공식 원문, 확인일, 관련 글의 순서로 작성한다. 일반적인 문장을 늘리는 것이 아니라 이용자의 선택을 줄여주는 정보가 들어가야 한다.

### 3단계: 저가치 URL 편집 판정

전체 게시물을 URL 단위로 검토해 다음 네 가지 중 하나를 기록한다.

- 유지: 독립적인 지역 정보와 출처가 있음
- 개선: 주제는 유효하나 장소·조건·비교가 부족함
- 통합: 같은 의도와 정보를 가진 글을 하나의 대표 글로 합침
- 정리: 실제 정보가 없거나 재사용 가치가 없는 페이지

판정표는 사이트맵, 검색 인덱스, 내부 관련 글, RSS가 함께 사용하도록 단일 파일에서 관리한다. `noindex` 수를 늘리는 것을 목표로 삼지 않는다.

### 4단계: 편집 신뢰성 정비

상단·하단·schema 날짜를 실제 확인 이력에 맞게 통일하고, 기사별로 원자료 기준일을 저장한다. 의료 글은 진단·치료 조언보다 기관 확인, 운영시간, 야간·주말 이용 절차 중심으로 제한한다. 출처 없이 “몇 분 안에”, “가장 빠른”처럼 정밀해 보이는 표현은 삭제하거나 근거를 추가한다.

반복 SVG 일러스트 8종을 모든 기사에 재사용한 것 자체가 정책 위반은 아니지만, 글의 지역성을 증명하지 못한다. 직접 만든 비교표·동선도·조건표·검수 기록처럼 해당 글의 판단을 보여주는 시각 자료를 우선 추가한다. 직접 방문하지 않은 장소를 방문한 것처럼 쓰거나, 생성 이미지로 실제 시설을 대체하지 않는다.

### 5단계: 모바일 UX와 기술 검증

- 홈 첫 화면에 핵심 카테고리 4~6개를 먼저 배치하고 영웅 이미지 높이를 줄인다.
- 지도 필터는 기본 접힘, 결과 요약 고정, 빈 결과 안내를 적용한다.
- 긴 표는 모바일에서 핵심 열을 먼저 보여주고 나머지는 상세 보기로 제공한다.
- 360·390·430px에서 홈, 허브, 기사, 지도, 정책·캘린더를 재검증한다.
- 변경 후 sitemap 200, canonical, robots, 내부 404, ads.txt 200, 실제 광고 크롤러 차단 여부를 확인한다.

## 6. 재심사 전 통과 기준

다음 조건을 만족한 뒤에만 변경 내용을 정리해 재검토한다.

- 대표 콘텐츠 8~12개가 운정의 구체적인 장소·조건·비교·공식 출처를 포함한다.
- 정책뉴스·캘린더·주차·지도에서 화면 문구와 실제 데이터가 일치한다.
- 33개 날짜 불일치가 해소되고, 모든 변동 정보에 확인일이 있다.
- 검색·사이트맵·RSS·내부 링크가 같은 공개 범위를 사용한다.
- 핵심 모바일 경로에서 결과가 필터보다 먼저 보이고, 빈 상태가 오해를 만들지 않는다.
- 새 글을 대량으로 추가하기보다 기존 글의 독립적인 가치를 검수할 수 있다.

이 조건은 승인 보장이 아니라, “가치가 별로 없는 콘텐츠” 사유에 대해 실제 개선 사실을 설명할 수 있는 최소 운영 기준이다.
