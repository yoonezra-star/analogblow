분류 규칙 점검 중 음식 글의 `sashimi`가 창호 용어 `sash`와 부분 일치하는 오탐을 발견해 수정했다. 이제 창호는 `window-sash`처럼 문맥이 포함된 용어로만 분류한다.

이번 작업은 미들웨어 응답에만 의존하지 않고, 비대표 생활수리 원본 HTML에도 다음 태그를 직접 추가했다.

```html
<meta name="robots" content="noindex, follow">
```

대표 가이드와 일반 생활정보 글에는 이 태그를 추가하지 않았다. 대표 URL은 메인 사이트맵과 `CORE_NAMED_POSTS` 허용 목록을 기준으로 유지한다.

## 짧은 글 후속 점검

- 색인 허용 게시글 중 본문 텍스트 1,200자 미만: 71개
- 비대표 생활수리 게시글 중 본문 텍스트 1,200자 미만: 136개

71개는 즉시 일괄 삭제하지 않고 Search Console의 실제 노출·색인 데이터를 확인한 뒤, 독립적인 검색 의도가 있는 글만 보강하고 겹치는 글만 대표 가이드로 통합한다.

## Search Console에서 확인할 항목

1. 페이지 색인 생성 보고서에서 `크롤링됨 - 현재 색인이 생성되지 않음`의 URL을 내려받는다.
2. `발견됨 - 현재 색인이 생성되지 않음`과 `중복 페이지`를 구분한다.
3. 대표 URL이 제외 목록에 들어간 경우 먼저 정식 URL·사이트맵·내부 링크를 확인한다.
4. 비대표 생활수리 URL은 정적 `noindex`가 반영된 뒤 재검증하고 색인 요청하지 않는다.
5. 정리 후 대표 허브와 대표 글만 우선 색인 요청한다.

이 로컬 보고서는 Search Console의 실제 상태를 대체하지 않는다. Google 재크롤링 이후의 제외 사유와 실제 색인 결과를 브라우저에서 별도로 확인해야 한다.
