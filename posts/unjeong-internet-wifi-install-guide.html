Home Network

운정 인터넷·와이파이는 요금제보다 집 안 배선과 공유기 위치를 먼저 보면 실패가 적습니다.

기가급 회선을 설치해도 공유기가 현관 통신단자함 안에 있거나 벽이 많은 구조라면 방 안 체감속도가 크게 떨어질 수 있습니다.

설치 전 체크

  • 주소 기준으로 원하는 통신사의 설치 가능 상품과 회선 종류를 확인합니다.
  • 거실·방의 랜포트가 실제 통신단자함과 연결되어 있는지 봅니다.
  • 공유기를 집 중앙에 둘 수 있는지, 단자함 내부 설치가 필요한지 확인합니다.
  • PC·게임기·TV처럼 안정성이 중요한 기기는 유선 연결 가능성을 먼저 봅니다.
  • 방이 많거나 복층이면 메시 와이파이 또는 추가 AP가 필요한지 확인합니다.

와이파이가 약할 때 원인부터 나눕니다

연결이 자주 끊김공유기 재부팅 반복보다 펌웨어·전원·과열·채널 간섭 확인

보안 설정도 같이 합니다

  • 공유기 관리자 계정과 Wi-Fi 비밀번호를 기본값에서 변경합니다.
  • 가능한 경우 최신 보안방식을 사용하고 오래된 암호화 방식은 피합니다.
  • 원격관리 기능을 사용하지 않는다면 끄는 것을 검토합니다.
  • 홈캠·스마트가전이 많다면 게스트망이나 별도 IoT망 지원 여부를 확인합니다.
  • 공유기 펌웨어를 최신 상태로 유지합니다.

입주 전에 준비하면 편한 것

  • 인터넷 설치일을 이사 당일보다 앞뒤 일정에 맞춰 미리 잡습니다.
  • 벽걸이TV·책상 위치를 정한 뒤 랜포트와 전원 위치를 확인합니다.
  • 통신단자함 안에 공유기·허브를 둘 경우 전원과 발열 공간을 봅니다.
  • 기존 임차인의 장비가 남아 있다면 반납 대상인지 확인합니다.
