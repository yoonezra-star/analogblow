운정 생활권을 지도처럼 빠르게 훑어봅니다.

주차장, 도서관, 공원, 문화시설, 보건시설을 운정 생활권 기준으로 묶었습니다. 현재는 공공데이터와 공식 출처 기반의 자체 지도검색이며, 카카오 지도 API 키를 연결하면 같은 데이터로 실제 지도를 붙일 수 있습니다.

데이터 기준

이 지도형 페이지는 파주시 공영주차장 현황, 파주시도서관 포털, 파주시 보건소, 파주문화재단, 운정호수공원 관련 공식 자료를 기준으로 구성했습니다. 위치 좌표는 실제 지도 API 연동 전까지 생활권 이해를 돕기 위한 시각화이며, 방문 전 공식 지도와 현장 안내를 확인해야 합니다.

  • 파주시 유료 공영주차장 현황
  • 파주시도서관 공식 포털
  • 파주시 보건소
  • 파주문화재단
